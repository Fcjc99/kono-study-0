# KONO Production Build 15.1 — Locked Cherry Tree Sprites & Evolution Art Standard

This corrective pass replaces the earlier generated tree graphics with the six user-approved transparent sprites and establishes them as the visual standard for all future Sanctuary evolution.

## Integrated tree progression

- Stage 0: quiet mound and first sprout
- Stage 1: small sapling
- Stage 2: developed young sapling
- Stage 3: mature green tree with buds
- Stage 4: first blossom canopy
- Stage 5: full mature bloom

## Rendering changes

- The complete approved sprite, including its mound, is rendered for every stage.
- All stages share the same source root anchor and runtime canvas.
- Morning, afternoon, evening, and night assets are pre-rendered from the approved source art.
- The whole tree landmark no longer rotates, pulses, breathes, or scales with wind.
- Stage changes use a calm crossfade.
- Only blossom stages receive a restrained petal accent.

## Evolution art lock

`docs/EVOLUTION_ART_LOCK.md` now defines the required style and six-stage PNG workflow for Home, Lanterns, Bamboo Grove, and all later map evolution systems.

No replacement Home, Lantern, or Bamboo stage sprites are invented in this pass. Those systems remain functionally preserved until their approved art sets are created.
