# KONO 22.8.10 — workspace and recovery

Sanctuary is the opening page. Saved work comes before editors, with a compact desktop sidebar and phone bottom navigation. Original Sanctuary artwork, phase colors, sprites and lighting are preserved.

## Included

- Unified record editing, completion/reopening, duplication and recoverable Trash. Notes can be unpinned without deleting them.
- Recent Undo/Redo with concurrent-change checks. Earned task credit survives reopening and recovery, preventing repeated completion from farming progress.
- Bulletin board order, note sizes, board/list view, subject filtering and paper/cork/plain surfaces.
- Forest, Ocean, Midnight and Paper themes, larger text, density and decoration preferences.
- Record search, browser Back/page restoration, device-local editor drafts and optional demo onboarding.
- Calendar agenda, study-plan completion/reopening and rescheduling, flashcard editing/duplication, editable weekly seasons and individual occurrence completion/skipping.
- Data format 3 accepts previous data and backups. Older clients must reload before writing; no account database or user records are replaced during source installation.

## Validation

Automated checks cover data ownership, concurrent saves, migration, Trash restoration, Undo/Redo, task credit, study scheduling, safe note rendering, calendar dates, Sanctuary progression, phase lighting and scene loading. Browser checks used isolated test data for draft recovery, completion/Undo/Redo, Trash/restore, search-to-editor and a fourteen-chapter plan with one chapter daily. Phone-width layouts were checked at 375–390 CSS pixels, including large text and themes.

## Release limits

Recent Undo/Redo lasts for the current session; Trash is saved with the account. Unsaved drafts are device-local, not cross-device records. Permanently removing a Trash entry is irreversible. In development, the interface accurately reports device-only saving. A real physical iPhone and a signed-in two-device acceptance test remain required before a broad production launch. This release adds no paid AI dependency and does not change site access permissions.
