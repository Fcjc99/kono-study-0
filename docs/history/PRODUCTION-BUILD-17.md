# KONO Production Build 17 — Bamboo Grove & Habitat Evolution

Build 17 activates the Bamboo Grove as a permanent, subject-linked Sanctuary feature using the supplied painterly-pixel bamboo artwork.

## Bamboo progression

Spanish and language-study task credits advance the grove through:

1. Stage 0 — Sleeping shoot
2. Stage 1 — First stalk
3. Stage 2 — Twin shoots
4. Stage 3 — Young cluster
5. Stage 4 — Established grove
6. Stage 5 — Mature grove

Thresholds: `0, 1, 2, 3, 5, 8` Spanish/language credits.

## Visual integration

- Six authored transparent PNG stages
- Separate morning, afternoon, evening, and night textures
- Fixed ground anchor on the upper Sanctuary terrace
- Calm crossfades for stage and time changes
- Phase-aware ground shadow
- Restrained leaf drift for established and mature stages
- No whole-object pulsing, bouncing, or rotation

## Habitat behavior

An evolved bamboo grove can become an occasional bird landing point. Weather, Reduced Motion, ambient density, and performance safeguards remain active.

## Save migration

The Sanctuary progression schema is now version 6. Existing profile saves migrate automatically; prior task credit and all earlier evolution stages remain intact.
