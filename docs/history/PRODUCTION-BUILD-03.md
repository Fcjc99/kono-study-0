# KONO Production Build 03 — Fluid Production Calibration

This build is the final corrective pass on the Production Build 02 fluid prototype.

## Fluid changes

- Reduced the default ocean and pond frame rate to a calm, painterly cadence.
- Replaced large diagonal bands with short, broken, mostly horizontal wave highlights.
- Reused fixed afternoon-derived geometry masks for all four time phases.
- Restored complete evening ocean coverage, including the upper-left water.
- Standardized waterfall geometry and motion across morning, afternoon, evening, and night.
- Rebuilt the generated water assets as transparent motion overlays so the approved paintings remain the visual authority.
- Removed broad source-image remapping that produced block and checker artifacts.
- Reduced waterfall mist so it supports the painted waterfall instead of obscuring it.

## Ambient changes

- Removed generic floating morning sparkles and persistent dew stars.
- Morning now uses restrained petals; afternoon uses restrained leaves.
- Water glints now stay attached to the water system.

## Production rule

Calm ocean motion uses horizontal, broken highlights. Diagonal flow is reserved for directional water such as waterfall ribbons or strong current.
