# KONO 22.7.37 — Lantern Terrace Evolution Working Pass

Scope: Lantern Terrace only.

This working pass preserves the existing runnable project and adds the approved structural direction for a continuous Stage 0→5 terrace evolution.

Evolution plan:
- Stage 0: locked bare terrace baseline.
- Stage 1: existing rear bench becomes the permanent seating spine; subtle built-in extension only.
- Stage 2: soft seating/cushions added without moving Stage 1 structure.
- Stage 3: permanent low tea table introduced at its final coordinate; fuller seating grows around the established bench.
- Stage 4: existing terrace posts become the structural origin of the pergola/trellis; planters/vines begin without moving deck/furniture.
- Stage 5: finished pergola, sofa-like built-in seating, flowers/vines, tea setup, richer furnishings while retaining all earlier anchor coordinates.
