# KONO v0.9.0 — Student Life Engine

## Study Seasons and Schedule Engine 1.0
- Every profile now owns its own complete Sunday–Saturday schedule.
- Create multiple semester, quarter, summer, sports, or finals schedules.
- Set season names and start/end dates.
- Select the active season used by Today’s Schedule.
- Add, edit, and remove unlimited daily blocks.
- Classify blocks as Study, Routine, Break, or Hobby.
- Copy one day into the next day and duplicate an entire week when creating a season.
- Newly created profiles receive an independent blank weekly schedule.
- Existing Summer 2026 users are migrated to the original weekly routine automatically.

## Compatibility
Existing profiles, assignments, notes, exams, themes, and sticky notes are preserved.
