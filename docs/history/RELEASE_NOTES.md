# KONO v0.7.7 — Tamagotchi Planner 2.0

A focused visual and UX rebuild based on the approved KONO direction.

- Restores the readable assignment-over-subject text hierarchy.
- Rebuilds task and subject rows with reliable left alignment.
- Adds a visible Tamagotchi-style Sakura Radio music dock.
- Makes daily schedule notes compact and collapsible instead of dominant.
- Upgrades corkboards with deep wood frames, layered cork, folded paper, varied rotations, realistic pins, washi tape, and a physical lower shelf.
- Strengthens the pastel game-planner identity without changing the underlying planner data model.
- Includes responsive tablet and mobile layouts.
