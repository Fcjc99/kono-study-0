# KONO Production Build 18 — Structural Home Evolution

## Structural cottage progression

The cottage now changes architecture rather than receiving only procedural plants, mats, and sparkles.

- Stage 0 — Starter cottage
- Stage 1 — Framed cottage
- Stage 2 — Porch cottage
- Stage 3 — Expanded cottage
- Stage 4 — Veranda home
- Stage 5 — Sanctuary lodge

Thresholds remain at 0, 10, 20, 35, 55, and 80 permanent task credits.

## Visual integration

- Six transparent source stages on a shared bottom-center anchor.
- Twenty-four morning, afternoon, evening, and night runtime textures.
- Scene-derived phase grading follows the same method used by the approved cherry tree.
- Smooth stage and phase crossfades.
- Stage-aware ground shadow.
- Restrained chimney smoke on developed houses, disabled by Reduced Motion and poor weather.
- Old procedural planter, flower, mat, and sparkle overlays removed.

## Testing

The existing Complete all / Reopen all controls on each subject can be used to move rapidly through cottage stages.
