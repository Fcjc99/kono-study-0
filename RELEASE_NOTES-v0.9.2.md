# KONO v0.9.2 — Mobile Color Picker Fit

- Paper and highlight palettes now remain fully inside the Notes and Exams editor boundaries.
- Added semantic paper/highlight picker classes so responsive rules no longer depend on fragile element order.
- Uses a three-column compact grid on small tablets, two columns on phones, and one column only on very narrow devices.
- Resized swatches, labels, selected checks, toolbar controls, and text-color controls for mobile.
- Removed the narrow side-by-side picker columns that caused clipping and unusable color choices.
- Desktop layout and existing data behavior are unchanged.
