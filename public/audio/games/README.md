# Arcade soundtracks

Each game plays its own looping track from this folder when it is here, and its built-in tune when it
isn't (src/arcadeAudio.ts). Files are MP3, about 1–2 minutes, made to loop.

| File | Game |
| --- | --- |
| `candy.mp3` | Candy crush |
| `gems.mp3` | Gem blitz |
| `meow.mp3` | Meowdoku |
| `flap.mp3` | Flappy KONO |
| `paper.mp3` | KONO.io |
| `blast.mp3` | KONO blast |
