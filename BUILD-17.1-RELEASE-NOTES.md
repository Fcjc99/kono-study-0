# KONO Production Build 17.1 — Bamboo Grove Art Replacement

This corrective build replaces the bright, circular-mound bamboo artwork from Build 17 with a quieter hillside habitat that matches the Sanctuary composition.

## Visual replacement

- Removed the separate round dirt-island appearance from all six bamboo stages.
- Rebuilt the grove from thinner, irregularly spaced stalks with varied height and lean.
- Shifted the palette from neon yellow-green to muted sage, olive, and forest greens.
- Added only sparse grass integration at the base so bamboo appears to grow through the existing hill.
- Reduced the mature grove footprint so it supports the cherry tree rather than competing with it.
- Moved the grove right and lower, closer to the terrace vegetation.

## Phase integration

- Morning, afternoon, evening, and night variants now blend with the local painted terrain color near the grove.
- Evening and night receive stronger value compression and reduced saturation.
- Shadows and falling leaves are smaller, dimmer, and less frequent.

## Preserved systems

Spanish-linked progression thresholds, profile isolation, save migration, landmark information, bird visits, weather response, and Reduced Motion behavior remain intact.
