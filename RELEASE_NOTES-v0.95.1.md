# KONO v0.95.1 — Weather Presence Pass

This update strengthens the Living Sanctuary weather states without turning them into screen overlays.

## Changes

- Ambient density now controls weather particle counts as well as leaves, petals, sparkles, and fireflies.
- Cloudy weather now includes slow background cloud banks and a clearer cool-light shift.
- Rain now has denser, brighter layered drops, deeper overcast lighting, cloud movement, and more frequent pond ripples.
- Breezy weather now keeps a continuous field of drifting leaf sprites rather than relying on occasional single leaves.
- Snow now uses larger, brighter flakes at a substantially higher baseline density with a cooler winter light.
- Mobile weather density was raised while retaining a performance reduction relative to desktop.
- Changing the debug density or Reduced Motion setting immediately rebuilds the active weather field.

The companion remains intentionally excluded.
