# KONO Production Build 13 — Task-Driven Sanctuary Evolution 1.0

## Goal
Turn completed planner work into permanent, profile-specific changes in the Sanctuary without exposing XP, coins, or game pressure.

## Cherry tree progression

| Stage | Completed-task credits | World state |
| --- | ---: | --- |
| 0 | 0–2 | Quiet dirt mound |
| 1 | 3–7 | Tiny sprout |
| 2 | 8–14 | Young sapling |
| 3 | 15–24 | Young flowering tree |
| 4 | 25–39 | Mature blossom tree |
| 5 | 40+ | Full bloom |

## Behavior

- Completing a task credits that task once and immediately advances the tree when a threshold is crossed.
- Unchecking a task does not destroy previously earned Sanctuary growth.
- Each study profile owns an independent tree stage.
- Existing completed assignments are migrated into the correct tree stage.
- Growth uses a calm scale-and-fade transition with a restrained petal moment at flowering stages.
- The tree responds to shared daylight and wind values.
- Reduced Motion keeps the evolution state change but removes the animated flourish and sway.
- The cherry-tree landmark now shows the current stage and next task threshold.

## Foundation for later evolution

The progression state remains ready for pond, home, garden, bridge, and lantern evolution. Those features are intentionally not activated in this build so the first progression loop can be reviewed in isolation.
